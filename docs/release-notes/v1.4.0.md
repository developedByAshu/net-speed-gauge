NetSpeedGauge 1.4.0: safer updates and fixes.

- **Signed updates:** an update installs only if it carries our release signature, and NetSpeedGauge asks before installing (Install or Later). Checking can still be set to Never
- Downloads use https only, from GitHub only
- Windows: settings and usage are saved off the taskbar thread, so the taskbar never waits on a disk write; DLLs load only from the Windows system folder; a rare drawing failure no longer closes the app
- Privacy: NetSpeedGauge connects only to GitHub, to check for updates. Only the app name is sent; GitHub sees your IP address. Nothing else leaves your computer

**Windows:** take `NetSpeedGauge-x64.exe`, or `NetSpeedGauge-arm64.exe` on a Windows on ARM PC. Windows may show a SmartScreen warning because the program is not code signed by Microsoft. Choose **More info**, then **Run anyway**.

**Mac:** take `NetSpeedGauge-mac-arm64.zip`, unzip it and move the app to Applications. The app is now signed with our own certificate. If macOS blocks the first launch, open **System Settings**, **Privacy & Security**, choose **Open Anyway**.
