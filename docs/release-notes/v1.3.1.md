NetSpeedGauge 1.3.1: it now keeps itself up to date.

- **Check for updates** in General: Launch, Daily (the default), Weekly, Monthly or Never, plus **Check now**. A new version downloads, is checked against its checksum and installs by itself
- The old update rate section is now called **Refresh**, so the two are not confused
- Settings is a little larger (720 by 720 on both Mac and Windows)
- Mac: a mouse wheel now scrolls Settings at a normal speed
- Windows: a touchpad now scrolls Settings smoothly, small two-finger scrolls included
- Privacy: NetSpeedGauge only connects to GitHub to check for updates. Nothing about you is sent

**Windows:** take `NetSpeedGauge-x64.exe`, or `NetSpeedGauge-arm64.exe` on a Windows on ARM PC. From this version on, updates install themselves. Your settings and usage stay as they are. Windows may show a SmartScreen warning because the program is not code signed yet. Choose **More info**, then **Run anyway**.

**Mac:** take `NetSpeedGauge-mac-arm64.zip`, unzip it and move the app to Applications. There is no version for Intel Macs. macOS blocks it the first time because the app is not signed by Apple. Open **System Settings**, **Privacy & Security**, choose **Open Anyway**, then open it again.
